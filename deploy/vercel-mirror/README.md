# Лендинг-зеркало для boldo-agency.ru

Что тут: `index.html` — лендинг Егора Кочнева, `vercel.json` — правило, по
которому ЛЮБОЙ путь на ЛЮБОМ субдомене показывает этот лендинг.

## Разовая настройка (делается один раз)

1. Установить Vercel CLI и войти:
       npm i -g vercel
       vercel login
2. Из этой папки развернуть проект:
       vercel --prod
   Vercel спросит имя проекта — запомни его, это и есть VERCEL_PROJECT_ID
   (виден в Settings → General → Project ID, вида `prj_…`).
3. Привязать домен. В кабинете Vercel → проект → Settings → Domains:
   • добавить `boldo-agency.ru`;
   • для режима **wildcard** (рекомендую) добавить ещё `*.boldo-agency.ru` —
     тогда любой субдомен работает сразу, без запросов к API;
   • указать у регистратора домена NS-серверы Vercel (Vercel подскажет какие)
     — иначе субдомены не получат ни DNS, ни SSL.
4. Токен для панели: Vercel → Account Settings → Tokens → Create.
   Это VERCEL_AUTH_TOKEN.

## Как это подключить в панели

Блок «Что напишем» → «Ссылка-зеркало {LINK}»:
- пиши в тексте `{LINK}` — панель подставит живой субдомен;
- режим **wildcard**: ничего больше не нужно, панель сама придумывает имена;
- режим **api**: впиши токен и Project ID, нажми «Проверить доступ к Vercel».
