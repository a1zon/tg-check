# Задача: поставить лендинг на boldo-agency.ru и включить субдомены-зеркала

Ты — ассистент с доступом к моему аккаунту Vercel. Нужно развернуть готовый
лендинг и настроить домен так, чтобы работал ЛЮБОЙ субдомен
`что-угодно.boldo-agency.ru` и показывал этот лендинг. Домен куплен и лежит
у регистратора, доступ к его DNS у меня есть.

## Что уже готово (в этой папке)

- `index.html` — сам лендинг.
- `vercel.json` — правило: любой путь на любом субдомене отдаёт `index.html`.

Ничего в этих файлах менять не нужно.

## Шаги

1. **Развернуть проект.** Из этой папки:
       vercel --prod
   При первом запуске Vercel спросит, привязать ли к проекту — создай новый,
   имя любое (например `boldo-landing`). Запомни его.

2. **Дать мне Project ID.** Vercel → проект → Settings → General → Project ID
   (вид `prj_XXXXXXXX`). Пришли мне его — он нужен панели.

3. **Привязать домены.** Vercel → проект → Settings → Domains → Add:
   - `boldo-agency.ru`
   - `*.boldo-agency.ru`  ← ОБЯЗАТЕЛЬНО, это и есть режим wildcard:
     без него случайные субдомены не будут работать.

4. **DNS.** Чтобы wildcard заработал и получил SSL, домен должен обслуживаться
   Vercel. Проще всего — переключить у регистратора NS-серверы на те, что
   покажет Vercel на шаге 3 (обычно `ns1.vercel-dns.com` / `ns2.vercel-dns.com`).
   Если менять NS нельзя — добавь у регистратора записи, которые попросит
   Vercel (для apex — A-запись, для `*` — CNAME на `cname.vercel-dns.com`).

5. **Создать токен для панели.** Vercel → Account Settings → Tokens → Create
   Token (scope — на нужную команду/аккаунт). Пришли мне значение токена
   ОДИН раз, безопасным способом — оно даёт доступ к управлению доменами.
   Если проект в команде (team), пришли ещё Team ID (`team_…`).

## Как понять, что всё вышло

Открой в браузере `https://test123.boldo-agency.ru` (любое имя перед точкой).
Должен открыться лендинг, с валидным замком (HTTPS). Если открывается —
готово, можно закрывать.

## Что вернуть мне тремя строками

- Project ID: prj_…
- Team ID (если есть): team_…
- Токен: (значение)

Дальше я впишу их в панель, и она будет сама генерить свежие субдомены
под рассылку.
