КАК ОТКРЫТЬ АККАУНТ (Linux)

1. Распакуй папку туда, где она останется жить.

2. Запусти в терминале:
       cd путь/к/папке
       ./открыть-аккаунт.sh
   (или двойным щелчком, если файловый менеджер умеет запускать скрипты)

3. Скрипт проверит прокси и покажет его IP, потом откроет ПУСТОЙ Telegram.
   Подтверди «Включить прокси» (Enable proxy) и закрой окно: Ctrl+Q.

4. Telegram откроется снова — с аккаунтом и через прокси.

5. Закончил — закрывай окно через Ctrl+Q. Мост выключится сам.

ЧЕГО НЕ ДЕЛАТЬ
  • Не выходить из аккаунта в Telegram: ключ у этого Telegram и у панели
    ОДИН, выход отзовёт сессию и панель потеряет аккаунт.
  • Не отключать прокси в настройках Telegram — иначе аккаунт выйдет
    с твоего IP, а панель ходит через прокси.
  • Папку после первого запуска не переносить: рядом лежит workdir
    с настройками Telegram.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  «Не найден Python 3»          →  sudo apt install python3
  «Не найден Telegram Desktop»  →  sudo snap install telegram-desktop
     или распакуй сборку с desktop.telegram.org в /opt/Telegram
