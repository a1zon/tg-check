КАК ОТКРЫТЬ АККАУНТ (macOS)

1. Распакуй эту папку куда-нибудь, где она останется жить —
   например в «Документы». Не запускай прямо из архива.

2. Первый раз: правой кнопкой по «Открыть аккаунт.command» → «Открыть»
   → в окне «Открыть». Так macOS один раз спросит про файл из интернета.
   Дальше хватит двойного щелчка.

3. Откроется Терминал, он проверит прокси и покажет его IP.
   Потом запустится ПУСТОЙ Telegram — без аккаунта.
   В нём подтверди «Включить прокси» (Enable proxy) и закрой окно: ⌘Q.

4. Telegram запустится снова — уже с аккаунтом и через прокси.
   Переписывайся как обычно.

5. Закончил — закрывай окно через ⌘Q. Мост выключится сам.

ЧЕГО НЕ ДЕЛАТЬ
  • Не выходить из аккаунта в Telegram (Настройки → Выйти). Ключ у этого
    Telegram и у панели ОДИН: выйдешь — панель потеряет аккаунт.
  • Не отключать прокси в настройках Telegram. Без него аккаунт выйдет
    в сеть с твоего домашнего IP, а панель ходит через прокси — Telegram
    увидит одну авторизацию из двух стран и может отозвать сессию.
  • Папку не переносить после первого запуска: рядом с файлом лежит
    workdir с настройками Telegram.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  «Не найден Python 3»  →  в Терминале: xcode-select --install
  «Не найден Telegram Desktop»  →  brew install --cask telegram-desktop
     (клиент «Telegram» из App Store не подходит — он не читает tdata)
  Ничего не открывается двойным щелчком  →  открой Терминал и выполни:
     cd путь/к/папке && ./"Открыть аккаунт.command"
