КАК ОТКРЫТЬ АККАУНТ (macOS)


КАКОЙ ТЕЛЕГРАМ НУЖЕН

Нужен Telegram Desktop — с сайта desktop.telegram.org либо командой
    brew install --cask telegram-desktop

НЕ ПОДХОДИТ «Telegram» из App Store (он же Telegram for macOS): это другая
программа, она не умеет открывать чужую папку с аккаунтом. Их легко
спутать — у обоих синяя иконка с самолётиком. Комплект различает их по
внутреннему имени и чужую молча не возьмёт: скажет, что не нашёл нужную.

Обе программы спокойно стоят рядом, удалять ничего не нужно.


1. Распакуй эту папку куда-нибудь, где она останется жить —
   например в «Документы». Не запускай прямо из архива.

2. ПЕРВЫЙ запуск — один раз через Терминал. Дальше хватит двойного щелчка.

   macOS блокирует любой скачанный скрипт, и на новых версиях кнопки «Открыть»
   в окне НЕТ (только «В корзину/Готово») — это защита, не именно наш файл.
   Первый раз запускаем в обход, это безопасно:

     • Открой Терминал: ⌘+Пробел → напиши «Терминал» → Enter.
     • В окне Терминала напечатай   bash   — слово bash и ПРОБЕЛ после него.
     • Перетащи в окно Терминала файл «Открыть аккаунт.command»
       (в строку подставится путь к нему).
     • Нажми Enter.

   Скрипт запустится и заодно снимет блокировку со ВСЕЙ папки. Поэтому со
   следующего раза «Открыть аккаунт.command» и «Убрать аккаунт.command»
   открываются обычным двойным щелчком — Терминал больше не нужен.

3. Откроется Терминал, он проверит прокси и покажет его IP.
   Потом запустится ПУСТОЙ Telegram — без аккаунта.
   В нём подтверди «Включить прокси» (Enable proxy) и закрой окно: ⌘Q.

4. Telegram запустится снова — уже с аккаунтом и через прокси.
   Переписывайся как обычно.

5. Закончил — закрывай окно через ⌘Q. Мост выключится сам.

КАК УБРАТЬ АККАУНТ С ЭТОГО КОМПЬЮТЕРА

Запусти «Убрать аккаунт с компьютера.command». Он закроет Telegram, открытый из этой
папки, и сотрёт файлы аккаунта. Дальше папку можно удалить.

ВАЖНО: выходить из аккаунта в самом Telegram для этого НЕЛЬЗЯ. Ключ у этого
Telegram и у панели ОДИН: выход отзовёт сессию целиком, и панель потеряет
аккаунт. Стереть файлы — безопасно.


ЧЕГО НЕ ДЕЛАТЬ
  • Не выходить из аккаунта в Telegram (Настройки → Выйти). Ключ у этого
    Telegram и у панели ОДИН: выйдешь — панель потеряет аккаунт.
  • Не отключать прокси в настройках Telegram. Без него аккаунт выйдет
    в сеть с твоего домашнего IP, а панель ходит через прокси — Telegram
    увидит одну авторизацию из двух стран и может отозвать сессию.
  • Папку не переносить после первого запуска: рядом с файлом лежит
    workdir с настройками Telegram.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  «Не найден Python 3»  →  в Терминале: xcode-select --install
  «Не найден Telegram Desktop»  →  brew install --cask telegram-desktop
     (клиент «Telegram» из App Store не подходит — он не читает tdata)
  macOS блокирует файл / не открывается двойным щелчком  →  это первый запуск,
     сделай его через Терминал (см. пункт 2: bash + перетащить файл + Enter).
     После первого раза блокировка снимается со всей папки сама.
