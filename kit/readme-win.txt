КАК ОТКРЫТЬ АККАУНТ (Windows)

1. Распакуй папку туда, где она останется жить (не запускай из архива).

2. Двойной щелчок по «Открыть аккаунт.bat».
   Windows может спросить «Защитник SmartScreen» → «Подробнее» →
   «Выполнить в любом случае».

3. Окно проверит прокси, потом откроется ПУСТОЙ Telegram.
   Подтверди «Включить прокси» (Enable proxy) и закрой окно.

4. Telegram откроется снова — с аккаунтом и через прокси.

5. Закончил — просто закрой Telegram. Мост выключится сам.

ЧЕГО НЕ ДЕЛАТЬ
  • Не выходить из аккаунта в Telegram: ключ у этого Telegram и у панели
    ОДИН, выход отзовёт сессию и панель потеряет аккаунт.
  • Не отключать прокси в настройках Telegram — иначе аккаунт выйдет
    с твоего IP, а панель ходит через прокси.
  • Папку после первого запуска не переносить: рядом лежит workdir
    с настройками Telegram.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  «Не найден Telegram Desktop»  →  поставь с desktop.telegram.org
  Окно мигает и закрывается     →  запусти «Открыть аккаунт.bat» из
     командной строки, чтобы увидеть сообщение об ошибке
