КАК ОТКРЫТЬ АККАУНТ (Windows)


КАКОЙ ТЕЛЕГРАМ НУЖЕН

Нужен Telegram Desktop — обычная программа с сайта desktop.telegram.org.
Скачивать «Telegram Desktop for Windows», ставить как обычно.

НЕ ПОДХОДЯТ:
  • Telegram из Microsoft Store — это другая сборка, она не умеет
    открывать чужую папку с аккаунтом. С ней комплект работать не будет.
  • Telegram Web в браузере — там другой способ входа.
  • Telegram на телефоне.

Как понять, какой у тебя стоит: открой «Параметры → Приложения» и найди
Telegram. Если написано «Telegram Desktop» — то, что нужно. Если просто
«Telegram» и установлено из Store — удали и поставь с сайта.

Комплект сам найдёт программу в обычных местах, в реестре и в PATH.
Если не найдёт — напишет, где искал, и ничего не запустит.


ЧТО ДЕЛАТЬ

1. Распакуй папку из архива в постоянное место — например в «Документы».
   ИЗ АРХИВА НЕ ЗАПУСКАТЬ: Windows откроет его во временной папке, и
   настройки потеряются при следующем запуске.

2. Двойной щелчок по «Открыть аккаунт.bat».
   Если появится синее окно «Защитник Windows SmartScreen» — нажми
   «Подробнее», затем «Выполнить в любом случае». Так бывает с любым
   файлом, скачанным из интернета.

3. Откроется чёрное окно. Оно проверит прокси и покажет, какой адрес
   виден снаружи. Это нормально, окно закрывать не надо — оно держит
   связь с прокси, пока ты работаешь.

4. ПЕРВЫЙ ЗАПУСК: откроется ПУСТОЙ Telegram, без аккаунта. Так задумано.
   Telegram спросит про прокси — подтверди «Включить прокси» (Enable
   proxy). Потом закрой окно Telegram.

5. Telegram откроется второй раз — уже с аккаунтом и через прокси.
   Дальше переписывайся как обычно.

6. В следующие разы шага 4 не будет: настройки сохранены, аккаунт
   откроется сразу.


ЧЕГО НЕ ДЕЛАТЬ

  • Не выходить из аккаунта в Telegram (Настройки → Выйти). Ключ у этого
    Telegram и у панели ОДИН: выйдешь — панель потеряет аккаунт.
  • Не отключать прокси в настройках Telegram. Без него аккаунт выйдет
    в сеть с твоего домашнего адреса, а панель ходит через прокси —
    Telegram увидит один аккаунт из двух мест и может отозвать сессию.
  • Не переносить папку после первого запуска: рядом с файлом лежит
    workdir с настройками Telegram.
  • Не запускать этот же аккаунт одновременно на двух компьютерах.


ЕСЛИ НЕ ПОЛУЧАЕТСЯ

Чёрное окно теперь не закрывается само — в нём написано, что пошло не так.
Пришли этот текст, по нему сразу видно причину. Частые случаи:

  «Не найден Telegram Desktop»
      Стоит версия из Microsoft Store либо не установлен вовсе.
      Поставь с desktop.telegram.org.

  «Прокси не отвечает»
      Нет интернета, либо прокси временно лёг. Telegram при этом НЕ
      запускается намеренно: иначе аккаунт вышел бы с твоего адреса.
      Подожди пару минут и запусти снова.

  Окно мигнуло и закрылось
      Запусти «Открыть аккаунт.bat» из командной строки — так текст
      ошибки останется на экране.
